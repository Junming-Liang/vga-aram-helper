MODIFIED-LIBRARY REBUILD ROUTE FOR RECIPIENTS

Use the source archive for the same application release and the documented
native Windows x64 build environment. Build/install ABI-compatible modified
Qt 6.11.2 and, when needed, modified PySide6/Shiboken6 from the corresponding
sources. Preserve the module versions/architecture expected by the application.
Install those replacement libraries into the packaging environment, retain the
application sources/resources, then rerun the supplied PyInstaller spec/build
steps. A normal build step that reinstalls the official pinned wheel can replace
your modified libraries; adapt or bypass that dependency-installation step after
installing replacements. Test that the rebuilt EXE actually loads the modified
library and that the native UI and OCR smoke tests pass. The distributor should
publish the concrete tested commands and any additional toolchain inputs with
the release; these general directions do not claim a rebuild has been verified.
