# VGA乱斗助手：独立本地参考原型 v0.2

这是一个已经实现、可用 Python 启动的手动查阅原型，新增可选的免费本地截图 OCR。它根据静态行为证据独立编写，方便检索英雄、海克斯、装备与组合说明。

**它不是完整桌面助手的复刻。没有自动识别游戏、悬浮窗、自动选择、客户端接入或 Windows 运行验证。**

另行对真实桌面客户端的静态分析显示，完整产品还包括 Electron/React、Windows 原生截图与悬浮层，以及远程 AI 服务。仅凭客户端和公开参考数据，不能重建其完整服务。本原型不使用提取出的凭据，不调用其私有后端，也不声称等价实现。

## 新增：截图识别与免费测试准备

- 已实测的本地 CPU 截图文字识别：见 `OCR_SETUP.md`。默认不启用，不调用付费 AI。
- Windows Actions 工作流仅允许手动运行，尚未执行：见 `WINDOWS_TESTING.md`。
- 基础 Python/HTTP 测试更新为 47 项，真实 OCR 合成图/API 测试和一张公开静态样图的有限检查通过；真实浏览器与 Windows 仍未通过验证。

## 30 秒启动

需要 Python 3.10 或更高版本，以及现代浏览器。普通查阅不需要 npm、pip 安装或互联网；可选 OCR 需要一次性安装官方依赖。

1. 解压本包。
2. 在该目录打开终端，运行：

   ```sh
   python server.py
   ```

   macOS / Linux 通常使用 `python3 server.py`。Windows 也可以双击 `start.bat`，或在终端使用 `py -3 server.py`。

3. 在**同一台电脑**浏览器打开 http://127.0.0.1:8765 。
4. 按 Ctrl+C 结束服务器。

如果端口已被占用：`python server.py --port 8767`，然后打开 http://127.0.0.1:8767 。

默认加载 4 位虚构英雄、4 个虚构海克斯、5 件虚构装备与 1 个组合。所有名称和数值都是原创测试样例，界面会明确显示“演示模式”。默认隐藏其中已移除的海克斯。**不能用演示数据指导真实游戏。**

## 已实现

- 英雄名称 / 别名搜索、定位筛选、参考胜率 / 中文名称排序；“辅助”包括软辅和硬辅
- 手动选择英雄后标注海克斯联动和陷阱；详情保留资料中的具体理由
- 海克斯名称 / 效果检索、棱彩 / 黄金 / 白银筛选、已移除条目警告
- 装备名称 / 别名检索、组合与分支查阅、详情中的相关条目跳转
- 海克斯 → 装备的透明规则分，推荐与陷阱分开显示，冲突资料明确标注
- 海克斯、装备和组合的本地收藏；损坏的收藏 JSON 不会阻止启动
- 中文输入法组合输入保护，分批加载，详情关闭 / Escape / 外部遮罩关闭，异步详情防止旧请求覆盖新页面
- 仅监听 127.0.0.1，拒绝非 localhost Host；只读 API；不加载外部图片、字体或脚本

## 胜率与日期必须这样理解

- 英雄或海克斯的 `winRate` 只是源资料发布的参考值。
- **英雄 × 海克斯配对胜率没有提供。** 本程序不会把一个海克斯的参考胜率伪装成所选英雄拿它后的胜率。
- 样本数、统计区间、地区、置信度与当前版本正确性均未验证。
- 被研究的公开快照中，最新可见更新日志是 **2026-07-17**，静态检视发生在 **2026-10-12 UTC**。这个日志日期并不证明每条数据的更新时间。
- 7 月快照已经陈旧；导入后界面会持续警告。导入时间不是数据更新时间。此项目不会自动联网刷新。
- 未提供的胜率显示“暂无数据”；无联动或陷阱记录也不代表不存在。

## 装备规则（可检查）

这些分数衡量资料关联强度，**不是胜率，也不随所选英雄变化**。

1. 海克斯 `items` 中的装备：100 分。
2. `specialItems`：94 分。
3. `trapItems`：独立警告列表，100 分；不会仅因陷阱记录进入推荐。
4. 组合分支在父组合或该分支包含所选海克斯时参与：核心装备 34 分，普通装备 18 分；分支匹配加 10；父组合匹配加 5。
5. 同一装备取最高分，不求和。保留核心标记和各条理由。
6. 缺少装备主条目的关联会排除并显示缺失提示。
7. 浏览器按分数降序、中文名称排序显示前 8 个。API 返回全部候选，供浏览器在截断前完成中文排序。
8. 推荐与陷阱冲突时同时保留并高亮，程序不替用户裁定哪条说明正确。
9. 父组合 `items` 可在资料详情查阅，但不参与这项推荐规则。无分支的组合不贡献组合规则分。

## 导入您有权使用的 JSON 数据

交付包**不包含**虎牙源程序、网页脚本、图标、图片、安装包或所捕获的真实数据集。公开可访问不等于可自由再分发；请先确认您的使用权限。

本原型没有数据下载器。它提供明确的本地导入路径：把已有且有权使用的 JSON 快照放入一个目录，至少包括以下文件各一份：

- `heroIndex-*.json`：以英雄名为键的对象
- `augments-*.json`：以海克斯名为键的对象
- `items-*.json`：以装备名为键的对象
- `relations-*.json`：以英雄名为键的联动 / 陷阱对象
- `combinations-*.json`：组合数组（源字段拼写为 `heros`）
- 可选 `changelogs-*.json`：用于显示最新可见日志日期

然后执行：

```sh
python import_data.py /path/to/authorized-json private-data.json
python server.py --data private-data.json
```

Windows 路径含空格时请加双引号。导入器只保留文字和必要关联字段，去除图片地址和 HTML 标记；不执行源代码、不加载外部资源。它拒绝覆盖已有文件，请给新快照换一个输出名。

也可以直接编写符合 `fixtures/demo.json` 结构的原创数据，并运行 `python server.py --data your-data.json`。顶层需包括 `heroes`、`augments`、`items` 对象；`relations`、`combinations` 和 `metadata` 可参照示例。

公开来源与已验证过的快照 URL 记录在 `SOURCE_NOTES.md`。它们仅用于来源说明，不保证链接继续有效或内容仍相同。

## 文件与隐私

- `server.py`：只读本地 HTTP 服务
- `engine.py`：原创适配器与推荐规则
- `import_data.py`：显式本地 JSON 导入
- `static/`：原创 HTML / CSS / JavaScript 界面
- `fixtures/demo.json`：原创虚构样例
- `tests/` 与 `reports/`：测试与明确的验证边界

服务器没有账户、凭据、游戏进程访问或自动更新；可选 OCR 显式关闭 ONNX Runtime 遥测。点击来源链接会由用户主动打开外部网站。收藏仅存在当前浏览器；清理浏览器数据、换浏览器或换端口可能导致收藏不可见。

这是带可选截图 OCR 的本地参考工具。真实数据、兼容性与玩法判断仍需要用户在当前游戏版本中核对。
